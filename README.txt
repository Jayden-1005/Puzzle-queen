PUZZLE QUEEN — STARTER PROJECT

This is an early Progressive Web App prototype.
It includes a simple profile stored only on this device, sample word riddles,
points, coins, and a demo virtual gift reward.

IMPORTANT LIMITATIONS
- This is not a published App Store or Google Play app.
- Profile details are stored locally; there is no secure account system.
- No cloud sync, real multiplayer, friend invitations, or live leaderboard.
- Coins and rewards are demo-only and have no cash value.

TO USE
Upload the files in this folder to a GitHub repository (upload the individual
files, not just this ZIP), then connect the repository to an HTTPS hosting
service such as Netlify. Once hosted, open the website in Safari and use
Share > Add to Home Screen to install it like an app.

Keep your passwords private. Do not upload passwords, API keys, or private data.
